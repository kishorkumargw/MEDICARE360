Put the SQLite JDBC driver jar files in this folder.

Needed files (run setup-driver.bat / setup-driver.sh to download them automatically):
  sqlite-jdbc-3.45.3.0.jar   https://repo1.maven.org/maven2/org/xerial/sqlite-jdbc/3.45.3.0/
  slf4j-api-1.7.36.jar       https://repo1.maven.org/maven2/org/slf4j/slf4j-api/1.7.36/

Any recent sqlite-jdbc version from https://github.com/xerial/sqlite-jdbc/releases also works.
